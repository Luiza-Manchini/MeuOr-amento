# Meu Orçamento

Aplicativo pessoal de controle financeiro que será desenvolvido com Power Apps (Canvas App), Power Fx e listas do SharePoint.

O objetivo é registrar receitas e despesas, acompanhar contas pagas e pendentes, planejar cada mês, definir metas de economia e visualizar um resumo financeiro no Dashboard.

O projeto também é uma oportunidade de estudar Power Apps, organização de tarefas com GitHub Projects, documentação e testes.

**Estado atual:** planejamento concluído e organização do Kanban em andamento. O aplicativo ainda não começou a ser desenvolvido.
